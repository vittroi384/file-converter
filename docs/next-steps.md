# 고도화 방향

각 항목은 이번 작업에서 실제로 측정했거나 부딪힌 한계에서 나왔다. 위에서부터 효과 대비 비용이 좋은 순.

## A. 품질·정확도
1. **색까지 보는 화질 지표**: 지금 SSIM은 밝기만 본다 → 색 번짐(특히 AVIF·WebP의 크로마 압축)을 못 잡는다.
   후보: SSIMULACRA2 또는 Butteraugli(WASM). 검증 방법은 그대로(정답표 + leave-one-out), 지표만 교체해 결과 비교.
2. **SVG 글자**: resvg WASM판은 시스템 글꼴이 없어 SVG 속 글자가 빠질 수 있다 → Pretendard 일부 글꼴을 resvg에 넣기(+1\~2MB, 지연 로딩).
3. **PDF 용량 줄이기 범위 확대**: 지금은 RGB/회색 JPEG만. Flate로 압축된 사진, CMYK, 중복 이미지 합치기, 글꼴 서브셋은 손대지 않는다.
4. **HEIC 메타데이터**: 촬영 날짜·회전값 유지 여부 선택(지금은 픽셀만 옮김). 위치 정보는 기본으로 지우기(개인정보).

## B. 성능
1. **큰 파일**: 1억 화소급 사진·수백 MB PDF는 아직 메모리에 통째로 올린다. 측정 먼저(메모리 최고점) → 타일 단위 처리·OPFS.
2. **SSIM WASM SIMD**: JS로는 512ms(1200만 화소)에서 더 줄지 않았다(대칭 커널 실험 효과 2%). SIMD로 2\~4배 기대, 같은 정답 비교로 검증.
3. **스마트 압축 병렬 탐색**: 지금은 한 장 안에서 순서대로 4번 인코딩. 첫 두 후보를 동시에 인코딩하면 체감 시간 절반 가능(워커 여유가 있을 때만).
4. **100장 일괄 처리 측정**: 풀 크기(코어-1, 최대 6)가 메모리 대비 맞는지 실기기(저가 안드로이드)에서 확인.

## C. 운영·모니터링
1. **외부 생존 확인(dead man's switch)**: 지금 구조는 API가 죽어도 알림이 오지만, **서버 전체(VM 포함)가 죽으면** 아무도 못 알린다.
   항상 울리는 Watchdog 알림을 외부 무료 서비스(healthchecks.io 등)로 보내고, 끊기면 그쪽이 알리게.
2. **실사용 합성 감시**: 1시간마다 실제 브라우저로 '사진 1장 변환'을 돌려 성공 여부를 지표로(배포 후 깨짐을 사용자보다 먼저 발견).
3. **배포 표시**: 배포 시각을 지표로 남겨 대시보드에 세로선 → '오류 급증'이 배포 때문인지 바로 보이게.
4. **SLO·오류 예산**: 성공률 99%를 목표로 30일 예산 소진 속도(burn rate) 알림. 단발 기준값보다 오탐이 적다.
5. **백업**: VictoriaMetrics 스냅샷·알림 설정 JSON을 OCI 객체 저장소로 주기 백업.

## D. 기능
1. **오피스 → PDF, 한글(hwp)**: 원래 계획대로 OCI 서버에서 LibreOffice + H2Orestart. 서버로 파일이 가는 유일한 기능이라 화면에 분명히 표시하고, 처리 후 즉시 삭제·보관 0을 지표로 증명.
2. **영상·음성**: ffmpeg.wasm(멀티스레드는 이미 교차 출처 격리가 돼 있어 바로 가능). 짧은 클립 GIF/MP4 변환, 음성 추출.
3. **배경 지우기, 사진 일괄 이름 바꾸기, 이미지 OCR**(Tesseract WASM, 한국어 학습 데이터 크기 확인 필요).
4. **변환 기록**: 기기 안(IndexedDB)에만 최근 결과를 보관해 다시 받기. 서버 저장 없음 유지.

## E. 개발 과정
1. **CI**: 깃헙 액션에서 `npm run check` + Playwright(크롬·파이어폭스·웹킷). 지금은 이 PC의 Edge 하나로만 확인했다 — **사파리(아이폰)는 미확인**이 가장 큰 공백.
2. **시각 회귀 테스트**: 이번에 스크린샷을 직접 봐서 잡은 문제(카드 5+1, 글자 쪼개짐, 점 몰림)를 기준 이미지 비교로 자동화.
3. **배포**: 완료. OCI VM에서 Docker Compose로 운영 중(2026-11-05\~, 변환은 브라우저에서 하므로 서버 부하는 작다). nginx 앞단 리버스 프록시가 Let's Encrypt로 HTTPS(DuckDNS 도메인), SECURE_COOKIE=true — [deploy.md](deploy.md).
