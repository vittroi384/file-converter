# 아이폰 실기기 점검 목록

Playwright의 WebKit·아이폰 화면 흉내로는 다 통과했지만, 진짜 사파리(iOS)에서만 나오는 차이가 있을 수 있다. 운영 주소(https://localconvert.duckdns.org)에서 아이폰으로 한 번씩 확인한다. 각 줄 옆에 ○/× 와 iOS 버전을 적어 주면 고친다.

| # | 해 볼 것 | 기대 |
|---|---|---|
| 1 | 사진 앱에서 HEIC 사진 1장 → 형식 바꾸기 JPG | 받은 JPG가 똑바로 서 있고(세로 사진), 사진 앱 '정보'에 위치가 없다 |
| 2 | 사진 10장 한꺼번에 → WebP → '모두 받기' | ZIP 하나로 받아지고 파일 앱에서 열린다 |
| 3 | 4800만 화소 사진(최신 아이폰 '최대 해상도') → 용량 줄이기 | 탭이 꺼지지 않거나, 꺼질 크기면 시작 전에 '약 X 필요, 한도 약 Y' 안내 |
| 4 | 캡처 화면 → 글자 추출(OCR) | 처음 한 번 4.5MB 받고, 한글·영어가 .txt로 |
| 5 | PDF 2개 → 합치기 → 파일 앱에서 열기 | 쪽 순서 그대로 |
| 6 | 스크롤: 첫 화면 → 맨 아래 | 고정 장면(탐색·동시 처리·개인정보)이 끊기지 않고, '187 KB' 같은 숫자가 '0 KB'로 깜빡이지 않는다 |
| 7 | 설정 → 손쉬운 사용 → 동작 줄이기 켜고 다시 | 장면이 멈춘 그림으로 보이고 레이아웃이 안 깨진다 |
| 8 | 가로 모드 | 옆으로 밀리는 곳 없음 |
| 9 | 공유 시트에서 사진 → LocalConvert(홈 화면에 추가한 경우) | iOS는 웹 공유 대상(share target)을 지원하지 않는다 → 안 보이는 게 정상 |
| 10 | 변환 → 새로고침 → '최근 변환' | 방금 결과가 남아 있고 다시 받기가 된다 |
